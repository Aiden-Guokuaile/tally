## 全局边界

- 只在带刘海的内建屏上显示；接外接屏或合盖时面板隐藏。不做菜单栏图标、不做外接屏。
- 面板永远纯黑（试过毛玻璃，看着更差，删了）；宽度固定 620（两侧各 19 是肩部弧线），高度跟着内容走。
- 一切数据都在本机：会话来自 Claude Code / Codex 的 hook，用量来自本地日志与各家官方接口（Claude 只读登录留下的 token，不刷新不回写），网络 / 系统 / 应用全走 macOS 公开 API。不收集、不上传。
- 不做自动更新、不做 Developer ID 签名与公证、不做沙盒（要读 `~/.claude`、`~/.codex`）、不做多语言。
- 依赖 macOS 15+、Apple Silicon（arm64 单架构二进制）、带刘海的内建屏；零第三方依赖。用量数据层移植自 Atoll（GPL-3），所以整个仓库 GPL-3，清单在 `NOTICE`。

## 验证的通用约定

- `swift test` 全绿是每次改完的门槛；真机相关的用例（网卡、Wi-Fi、菜单栏 app）在环境不满足时 `XCTSkip`，不算失败。
- 截图坐标按 14 寸内建屏（1512 × 982pt）算：面板居中、宽 620，`screencapture -R256,0,1000,480 -x <文件>` 能包住展开态；别的机器改 x 与宽即可。
- `open -a Tally --args --open <page>` 让面板启动即展开到那页且不自动收起；`pkill -x Tally` 之后要等 `pgrep -x Tally` 查不到再 `open`，否则参数被没退干净的旧实例吞掉。
- hook 与会话文件的验证用 `TALLY_SESSIONS_DIR` 指到临时目录，不碰真实目录。
